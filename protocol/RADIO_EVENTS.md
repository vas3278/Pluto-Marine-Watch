# PMW radio events v1
Draft wire contract. HTTP stream uses binary frames: ASCII PMW1 (4 bytes), unsigned big-endian uint32 JSON header length, uint32 payload length, UTF-8 JSON header, binary payload. Limits: header 16384 bytes, payload 1048576 bytes. Reject invalid lengths before allocation.
Header: protocol_version=1, device_id, boot_id, event_id, sequence (nonnegative integer), type (EVENT_START, AUDIO, DATA, EVENT_END, GAP), frequency_hz, channel, modulation, monotonic_sample_index, start_utc, clock_synchronized. UTC nullable when unknown. AUDIO: codec pcm_s16le or opus, sample_rate_hz, channels=1; Opus packet framing to be finalized. DATA: format, integrity_valid. END: end_utc, duration_ms, dropped_samples, signal_dbfs, noise_dbfs, snr_db, clipping. GAP: missing sequence range or sample count. Each frame includes payload_crc32 (IEEE CRC32 unsigned integer). No authentication implied by CRC.
Sequence starts at zero per event; deduplicate by device_id, boot_id, event_id, sequence. ACK only after durable consumer storage; resume by server-issued cursor, expired cursor explicitly reports loss. Slow consumers must not block RX. PCM is baseline interoperable format. Transport authentication and authorization required on deployed networks.
